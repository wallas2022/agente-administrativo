# PP-09 — Segregación de funciones

**Versión:** 0.1.0
**Fecha:** 2026-09-24
**Relacionado con:** HU-09 / RNF-02 · docs/04-pruebas/plan-pruebas-prototipo.md · Entrega 1 · **Bloqueante para salida del piloto**

## Objetivo

Verificar que el sistema bloquea la autoaprobación (RN-07).

## Precondición

Usuario Analista con documento cargado y hallazgos generados.

## Datos de entrada

Un documento cargado por el usuario de prueba analista1.

## Pasos

1. Intentar decidir sobre los hallazgos con el mismo usuario analista1 (rol Revisor asígnado también a esa cuenta, si aplica).
2. Repetir con un usuario Revisor distinto.

## Resultado esperado

El sistema bloquea la decisión cuando el usuario coincide con quien cargo; la permite cuando es distinto.

## Umbral / métrica

0 autoaprobaciónes permitidas
