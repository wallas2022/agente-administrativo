# PP-08 — Uso solo de fuentes vigentes

**Versión:** 0.1.0
**Fecha:** 2026-09-24
**Relacionado con:** HU-11 / RF-16 · docs/04-pruebas/plan-pruebas-prototipo.md · Entrega 1 · **Bloqueante para salida del piloto**

## Objetivo

Verificar que el sistema nunca cita una version obsoleta de una fuente cuando existe una vigente.

## Precondición

Al menos una fuente de conocimiento con dos versiones (una vigente, una obsoleta) cargada via CU-08.

## Datos de entrada

Fuente normativa versionada; documentos que la referencian.

## Pasos

1. Actualizar una fuente de conocimiento a una nueva version (la anterior pasa a obsoleta).
2. Ejecutar análisis que consulten esa fuente.
3. Revisar las citas de los hallazgos generados.

## Resultado esperado

Ningun hallazgo cita la version obsoleta cuando existe una vigente equivalente.

## Umbral / métrica

0 citas a versiones obsoletas
