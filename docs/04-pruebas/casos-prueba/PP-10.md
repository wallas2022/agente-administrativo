# PP-10 — Permisos por área

**Versión:** 0.1.0
**Fecha:** 2026-09-24
**Relacionado con:** HU-02 / RF-02 · docs/04-pruebas/plan-pruebas-prototipo.md · Entrega 1 · **Bloqueante para salida del piloto**

## Objetivo

Verificar que un usuario no puede acceder a documentos de un área distinta a la suya.

## Precondición

Usuarios de al menos dos áreas distintas (p. ej. Contabilidad y Legal) con documentos propios cargados.

## Datos de entrada

Un documento cargado por el área Contabilidad y un usuario autenticado del área Legal.

## Pasos

1. Autenticarse como usuario del área Legal.
2. Intentar abrir o listar el documento cargado por Contabilidad.

## Resultado esperado

El sistema deniega el acceso al documento de otra área.

## Umbral / métrica

0 accesos a documentos de otra área
