# PP-17 — Ahorro de tiempo vs. revisión manual

**Versión:** 0.1.0
**Fecha:** 2026-09-24
**Relacionado con:** OE-07 · docs/04-pruebas/plan-pruebas-prototipo.md · Entrega 1

## Objetivo

Comparar el tiempo de revisión asístida por el agente contra la linea base de revisión manual.

## Precondición

Linea base de tiempo manual registrada (hasta 60 min, ver tests/dataset/README.md); mediciones de PP-12 disponibles.

## Datos de entrada

Tiempos de revisión manual (linea base) y tiempos con el agente (PP-12) para los mismos tipos de documento.

## Pasos

1. Calcular la reducción porcentual de tiempo por documento: (tiempo manual - tiempo con agente) / tiempo manual.
2. Promediar sobre la muestra de documentos complejos.

## Resultado esperado

La reducción de tiempo alcanza la meta.

## Umbral / métrica

>= 83 % (60 -> <= 10 min)
