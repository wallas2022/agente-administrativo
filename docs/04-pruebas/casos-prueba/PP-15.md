# PP-15 — Restauración desde respaldo

**Versión:** 0.1.0
**Fecha:** 2026-09-24
**Relacionado con:** RNF-07 · docs/04-pruebas/plan-pruebas-prototipo.md · Entrega 1

## Objetivo

Verificar que el sistema puede restaurarse desde un respaldo dentro del RTO definido.

## Precondición

Respaldo diario configurado (Proxmox Backup Server + volcado de PostgreSQL/MinIO/Qdrant).

## Datos de entrada

Snapshot/respaldo más reciente de la VM stage.

## Pasos

1. Simular una pérdida de la VM o de sus datos.
2. Ejecutar el procedimiento de restauración (ver docs/06-operacion/respaldo-y-recuperacion.md).
3. Medir el tiempo desde el inicio de la restauración hasta el sistema operativo de nuevo.

## Resultado esperado

El sistema queda operativo dentro del tiempo objetivo.

## Umbral / métrica

<= 4 h de recuperacion (RTO)
