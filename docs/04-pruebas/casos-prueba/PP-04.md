# PP-04 — Conservación de formato del archivo corregido

**Versión:** 0.1.0
**Fecha:** 2026-09-24
**Relacionado con:** HU-10 / RF-14 · docs/04-pruebas/plan-pruebas-prototipo.md · Entrega 1

## Objetivo

Verificar que el documento corregido generado tras la aprobación conserva el formato original sin daño.

## Precondición

Analisis con al menos un hallazgo aceptado por un Revisor, para cada tipo de documento soportado.

## Datos de entrada

Un documento por formato (xlsx, docx, pptx, pdf digital) con hallazgos aceptados.

## Pasos

1. Aceptar un subconjunto de hallazgos como Revisor.
2. Descargar el documento corregido generado.
3. Abrir el archivo con la aplicacion nativa del formato y verificar estilos, formulas y estructura.

## Resultado esperado

El archivo abre sin errores y conserva estilos, formulas (Excel) y estructura originales; solo cambia lo correspondiente a los hallazgos aceptados.

## Umbral / métrica

100 % de los archivos abren sin daño y conservan estilos
