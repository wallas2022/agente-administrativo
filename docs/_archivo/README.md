# docs/_archivo/

Snapshots de los archivos fuente del proyecto (`docs/_fuente-proyecto/`) tal como se recibieron, conservados después de integrarlos a la ubicación canónica en `docs/`. No son la fuente de verdad vigente — para el contenido vigente, usar los documentos referenciados por ID en `docs/00-rol-y-lineamientos.md`.

Cada subcarpeta `fuente-AAAA-MM-DD/` corresponde a una entrega de archivos fuente en esa fecha.
