# PP-12 — Tiempo por documento complejo (solo CPU, en stage)

**Versión:** 0.1.0
**Fecha:** 2026-09-24
**Relacionado con:** RNF-04 · docs/04-pruebas/plan-pruebas-prototipo.md · Entrega 1

## Objetivo

Medir el tiempo de análisis de documentos complejos bajo el modelo objetivo, en el ambiente stage.

## Precondición

Ambiente stage disponible (desde 28-oct-2026) con el modelo objetivo cargado.

## Datos de entrada

Los 5 documentos complejos del dataset (varias hojas, > 5,000 filas o > 50 paginas).

## Pasos

1. Ejecutar el análisis de cada documento complejo en stage.
2. Registrar el tiempo desde la carga hasta el resultado final.
3. Calcular el percentil 90 (p90) sobre las mediciones.

## Resultado esperado

El tiempo p90 no supera el umbral.

## Umbral / métrica

<= 10 min (meta 5-10 min); solo válido medido en stage
