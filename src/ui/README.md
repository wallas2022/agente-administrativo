# src/ui

Interfaz de usuario para carga de documentos, visualización de hallazgos, revisión/aprobación y consulta de bitácora.

Respuestas de `src/api`.

## Salidas

Interacciones de usuario (carga, aprobación, rechazo, comentarios) enviadas a `src/api`.
