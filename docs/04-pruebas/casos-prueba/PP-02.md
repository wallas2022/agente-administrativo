# PP-02 — Exactitud de cifras reportadas (Q y $)

**Versión:** 0.1.0
**Fecha:** 2026-09-24
**Relacionado con:** RNF-03 · docs/04-pruebas/plan-pruebas-prototipo.md · Entrega 1 · **Bloqueante para salida del piloto**

## Objetivo

Verificar que ningún cálculo numerico (totales, cuadres, montos) reportado por el sistema es generado o alterado por el LLM.

## Precondición

Dataset de Excel contables con montos en Q y en $ conocidos.

## Datos de entrada

Subconjunto de Excel contables del dataset con cifras de referencia verificadas manualmente.

## Pasos

1. Ejecutar el análisis contable sobre cada documento.
2. Comparar cada cifra citada en los hallazgos (montos, totales, diferencias de cuadre) contra el cálculo manual de referencia.

## Resultado esperado

Toda cifra citada coincide exactamente con el cálculo determinista de referencia.

## Umbral / métrica

0 cifras incorrectas
